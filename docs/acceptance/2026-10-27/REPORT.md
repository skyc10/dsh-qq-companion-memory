关联：REG-08、UI-01，后续真实宿主与页面验收均受阻。

最小复现：在基于现用镜像、包含本次最新构建插件的候选镜像中，挂载当前已停机的专用 `/data`，执行：

```sh

```

实际：退出码1；`dsh: pnpm was not found; install pnpm and make it available on PATH.`；底层日志为 `spawn pnpm ENOENT`。`command -v corepack` 存在，`command -v pnpm` 无输出。
